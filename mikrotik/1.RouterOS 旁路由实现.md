# RouterOS 旁路由实现

主路由用 `routing-mark` 做策略路由：命中规则的流量下一跳走到旁路由，其余流量仍走主路由 WAN。

域名如何变成 IP 列表，见 [使用 RouterOS 进行简单的域名分流](/mikrotik/domain-split/)。

## 环境

| 角色 | 地址 | 说明 |
| --- | --- | --- |
| 主路由 LAN | `192.168.88.1` | RouterOS，客户端默认网关、DNS |
| 旁路由 | `192.168.88.6` | 软路由，负责代理/特殊出口 |
| 客户端 | `192.168.88.15` | 需要被分流的设备 |
| LAN | `192.168.88.0/24` | MikroTik 默认网段 |
| LAN 接口 | `bridge` | 按实际接口改 |

拓扑：

```
192.168.88.15  ──默认网关──►  主路由 192.168.88.1
                                    │
                     命中分流的包     │  其余包走 WAN
                                    ▼
                             旁路由 192.168.88.6
                                    │
                                    ▼
                             主路由 WAN ──► 互联网
```

客户端默认网关仍是主路由，不要改成旁路由。主路由按规则把部分流量转交给旁路由。

## 旁路由侧要求

主路由只负责把包丢给旁路由。旁路由自己需要：

1. 开启 IP 转发。
2. 常用如 Clash，开启 TUN 接管流量。Mac Mini 侧见 [Mac Mini + Clash 做旁路由](/mikrotik/macmini-clash/)。

## 主路由配置

以下按 **RouterOS 7**。`new-routing-mark` 必须和 routing table 同名。地址按上面「环境」替换。

### 1. 创建策略路由表

```routeros
/routing table
add name=to-bypass fib
```

### 2. 在 `to-bypass` 表添加默认路由

```routeros
/ip route
add dst-address=0.0.0.0/0 \
    gateway=192.168.88.6@main \
    routing-table=to-bypass \
    distance=1 \
    comment="pbr: default via bypass"
```

`@main`：下一跳在 `main` 表里解析。`to-bypass` 表只有默认路由，不写 `@main` 时网关可能解析失败，路由变 inactive。

可选：加 `check-gateway=ping`。旁路由挂了这条路由会失效；若要回落到主路由 WAN，再在同一张表加一条更大 `distance` 的默认路由。

### 3. 需要走旁路网关的客户端

```routeros
/ip firewall address-list
add list=pbr-clients \
    address=192.168.88.15 \
    comment="pbr client"
```

多台设备继续往 `pbr-clients` 里加。

### 4. 标记客户端的外部单播流量

先跳过局域网，再给 `pbr-clients` 的出网单播打 `to-bypass`：

```routeros
add chain=prerouting \
    src-address=192.168.88.6 \
    action=accept \
    comment="pbr: skip bypass"
add chain=prerouting \
    action=mark-routing \
    src-address-list=pbr-clients \
    new-routing-mark=to-bypass \
    passthrough=no \
    comment="pbr: mark clients"
```

### 5. 对送往旁路网关的策略流量做 SNAT

```routeros
/ip firewall nat
add chain=srcnat \
    action=masquerade \
    src-address-list=pbr-clients \
    routing-mark=to-bypass \
    out-interface=bridge \
    comment="pbr: SNAT to bypass"
```

`out-interface` 改成实际 LAN 接口。

srcnat 的目的是让流量到旁路由后回到主路由。旁路由和主路由在同一网段时需要这样。
