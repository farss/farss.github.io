# Mac Mini + Clash 做旁路由

主路由策略路由见 [RouterOS 旁路由实现](/mikrotik/routeros-bypass/)。本文只写旁路由这一侧：Mac Mini 跑 Clash（mihomo / Clash Meta），用 TUN 接管被主路由丢过来的包。

## 环境

与 [RouterOS 旁路由实现](/mikrotik/routeros-bypass/) 相同。Mac Mini 就是那台旁路由。

| 角色 | 地址 |
| --- | --- |
| 主路由 | `192.168.88.1` |
| Mac Mini（旁路由） | `192.168.88.6` |
| 客户端 | `192.168.88.15` |

Mac Mini 默认网关指向主路由，**不要**把自己当客户端的网关。

## 1. 固定 LAN 地址

有线接入主路由 LAN。系统设置里把网卡改成手动：

- IP：`192.168.88.6`
- 掩码：`255.255.255.0`
- 路由器：`192.168.88.1`
- DNS：`192.168.88.1`（本机解析走主路由即可；给别人用的干净 DNS 由 Clash 提供）

## 2. 别让它睡着

旁路由要一直转发。系统设置 → 能量：接电源时防止自动休眠，并允许网络唤醒。

## 3. 打开 IP 转发

macOS 默认不转发。Clash 的「允许局域网」**不会**帮你开这个开关。

```sh
sudo sysctl -w net.inet.ip.forwarding=1
```

重启后失效的话写入：

```sh
echo 'net.inet.ip.forwarding=1' | sudo tee -a /etc/sysctl.conf
```

确认：

```sh
sysctl net.inet.ip.forwarding
# net.inet.ip.forwarding: 1
```

## 4. Clash TUN

用 mihomo / Clash Verge / FlClash 一类带 Meta 内核的客户端。必须 **TUN**：主路由送来的是普通 IP 包。

## 5. 给主路由用的 DNS

[使用 RouterOS 进行简单的域名分流](/mikrotik/domain-split/) 里的 `split-fwd` 指到 `192.168.88.6`。Clash 必须在 **53** 端口做真实解析（上一节 `dns.listen`）。macOS 绑 53 通常也要服务模式。

不要劫持主路由自己的查询之外的东西；主路由不要 dstnat 旁路由的 53。


## 注意
- Clash Verge：TUN stack 改成 system 。不要用 gvisor 做旁路由，否则可能会比较慢
- 只用 Wi-Fi 时关掉「专用 Wi-Fi 地址」，地址漂了主路由下一跳就无效。有线更稳。
- Mac 同时连接了有线和 wifi，也可能导致变慢
