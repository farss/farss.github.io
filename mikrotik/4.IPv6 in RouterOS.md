# IPv6 in RouterOS

在 RouterOS 上开 IPv6 本身很简单。前提是运营商把宽带改成桥接，由 RouterOS 自己 PPPoE 拨号。

## 1. 拿前缀、给 LAN 发 RA

拨号成功后：

```routeros
/ipv6 dhcp-client
add interface=pppoe-out1 request=prefix pool-name=wan6 add-default-route=yes

/ipv6 address
add interface=bridge from-pool=wan6

/ipv6 nd
set [find default=yes] interface=bridge mtu=1492
```

`pppoe-out1`、`bridge` 按实际接口改。ND 要打在 LAN 桥上，下面的机器才会收到 RA、自动拿到公网 IPv6。

以太网帧载荷默认 1500 字节。PPPoE 头占 8 字节，所以 IP 包最大只能 1492，这就是链路 MTU。

一个 IPv6 TCP 包长这样：

```
IPv6 头 40  +  TCP 头 20  +  数据（MSS）
|----------- 合计不能超过 1492 -----------|
```

MSS 是「这一段 TCP 最多能装多少用户数据」，所以：

```
1492 − 40 − 20 = 1432
```

ND 通告的是 **MTU=1492**，不是 MSS。主机收到 RA 后自己减掉两个头。IPv4 头只有 20 字节，同样 1492 的 MTU 下 IPv4 MSS 是 1452；IPv6 头多 20，MSS 就要再小 20。

不在 ND 里把 MTU 降下来的话，LAN 里的机器仍按以太网 1500 组包。大包到 PPPoE 口装不下，又常常收不到 ICMPv6 Packet Too Big，表现就是小请求正常、传文件或打开大页面对死。

## 2. 放行入站端口

RouterOS 的 IPv6 防火墙比较完整，LAN 里机器的端口默认从外面进不来。运营商也常封 80、443，下面用 `8080` 举例。

```routeros
/ipv6 firewall filter
add chain=forward action=accept protocol=tcp dst-port=8080 \
    comment="allow wan tcp 8080"
```

这条必须放在 `defconf: drop everything else not coming from LAN` **前面**。

## 3. 验证

本机 `ifconfig` 看有没有公网 IPv6，例如：

```
inet6 240e:37a:24d1:2600:106a:18f5:e9e4:xxxx prefixlen 64 autoconf secured
```

连通性测试：<https://test-ipv6.com/index.html.zh_CN>

测试从外面访问本机端口：在**要被访问的那台机器**上开 HTTP（不是 RouterOS 上）。
```sh
python3 -m http.server 8080
```

手机关掉 Wi-Fi，用蜂窝访问：

```
http://[240e:37a:24d0:aa00:18d4:7283:802e:8470]:8080/
```

方括号不能省。地址换成这台机器当前的公网 IPv6。

## 4. DDNS

IPv6 会变，常见是 3–7 天一次，有时更短。直接记地址不合适，用 DDNS 把当前 AAAA 刷到域名上，例如 [ddns-go](https://github.com/jeessy2/ddns-go)。

## 5. macOS 选哪个地址

`ifconfig` 会列出多个 IPv6。给 DDNS 用时去掉 `deprecated`、`temporary`，只留公网地址：

```sh
ifconfig | grep 'inet6 240e' | grep -v deprecated | grep -v temporary | awk '{print $2}'
```

`240e` 是电信前缀，按自己运营商改。`temporary` 是隐私扩展，会轮换；`deprecated` 是已经作废的旧地址。
